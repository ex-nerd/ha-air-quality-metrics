# Developer Instructions

## 1. Initial Setup

Clone the repository and install the project dependencies (including testing and quality assurance tools):

```bash
git clone https://github.com/ex-nerd/ha-air-quality-metrics.git
cd ha-air-quality-metrics
uv sync
```

## 2. python environment

This project uses `uv` for modern, fast Python package and environment
management. 

I am a fan of [`direnv`](https://direnv.net/), so have included a `.envrc.example` file that you can
copy and use to automatically set up and activate the python venv:

```bash
cp .envrc.example .envrc
direnv allow
```

If you don't use `direnv`, you will have to set up the venv manually:

```bash
uv venv
source .venv/bin/activate
export PYTHONPATH="${PWD}:${PYTHONPATH}"
```

### 2. Testing and Static Analysis

We enforce type safety, coding guidelines, and strict asynchronous environment compliance across our components.

Run the test suite against Pytest with Home Assistant loop tracking:

```bash
uv run test
```

Run static type checking and structural checks:

```bash
uv run typecheck
```

## 3. Local Deployment

Until I put in the time to set up a devcontainer and figure out how to populate
it with recent useful data, development is managed locally and previewed by
deploying a copy of this integration to my live server running Home Assistant
OS.

The project includes an optimized `rsync` deployment script to sync changes to
the server. Because the official SSH app for HA OS does not include rsync, if
you use HA OS you will also need to install the community [Advanced SSH & Web
Terminal Add-on](https://github.com/hassio-addons/app-ssh) and change the
configuration from the default `hassio` user to `root` so the deploy script can
write to the `config/custom_integrations` directory.

### Environment Configuration

Create a local configuration override file by copying our template:

```bash
cp .env.example .env
```

Open your new `.env` file and populate your development environment variables:

```bash
HA_SERVER_IP="192.0.2.1"
```

*(Note: If your username, etc. are already handled by your local `~/.ssh/config`
file, you should only need `HA_SERVER_IP` and can leave the other properties
commented out)*

### Executing the Sync

Whenever you wish to preview changes to this integration, push the updates to
your server over SSH by running:

```bash
uv run deploy
```

Remember to restart Home Assistant via the UI after syncing to force it to flush
its memory and reload the modified integration package.

## Logo/Icon

I'm not an artist, so the icon is just [mdi:air-filter](https://pictogrammers.com/library/mdi/icon/air-filter/)
updated with `fill="#60AAF3"` to match the default Home Assistant color.
I'm open to submissions for a new icon not generated by AI.

The icons are rendered from the original SVG via imagemagick, and then processed
through [ImageOptim](https://imageoptim.com/mac) to further reduce the file size:

```bash
magick -background none -density 2048 air-filter.svg -resize 256x256 icon.png
magick -background none -density 2048 air-filter.svg -resize 512x512 icon@2x.png
```
